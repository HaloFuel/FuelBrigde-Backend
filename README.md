# FuelBridge Backend

API REST del proyecto FuelBridge (HaloFuel), construida con Spring Boot 4, Java 26, arquitectura DDD por Bounded Contexts y MySQL.

## Bounded Contexts

- IAM (Identity & Access)
- Ordering
- Payment
- Catalog
- Fulfillment
- Notification
- Reporting
- Inventory
- Equipment

## Stack

- Java 26 + Spring Boot 4
- Spring Data JPA / Hibernate
- MySQL
- JWT (io.jsonwebtoken)
- springdoc-openapi (Swagger UI en `/swagger-ui.html`)
