# T09.16 - Auditoría previa a la migración de datos

## Objetivo

Verificar la disponibilidad de los datos originales de Equipment e Inventory antes de ejecutar su migración hacia los microservicios independientes de FuelBridge.

## Inspección realizada

Se ejecutó el script `docker/mysql/migrations/00-inspect-legacy-schemas.sql` sobre MySQL 8.4, utilizando Docker Compose.

Los resultados obtenidos fueron:

| Entidad | Esquema de destino | Tabla de destino | Registros |
|---|---|---|---|
| Equipment | fuelbridge_equipment | equipment | 0 |
| FuelProduct | fuelbridge_inventory | fuel_products | 0 |

No se encontraron las tablas originales `equipment` ni `fuel_products` en el esquema `fuelbridge_platform`.

La búsqueda en `information_schema.tables` confirmó que únicamente existen las tablas de destino dentro de la instancia local inspeccionada.

## Estado de la migración

**Pendiente por falta de datos de origen.**

La estructura de las tablas de destino está disponible. Sin embargo, no se dispone de registros originales en esta instancia de MySQL para realizar una migración efectiva.

## Acciones pendientes

1. Identificar un respaldo o exportación de la base de datos anterior.
2. Verificar las columnas y los identificadores originales.
3. Preparar scripts de transferencia que conserven la integridad de los datos.
4. Comprobar los conteos antes y después de la migración.
5. Documentar las evidencias de ejecución.

## Conclusión

Se completó la auditoría de esquemas y se identificaron las estructuras de destino. La transferencia de datos permanece pendiente hasta disponer de una fuente verificable.
